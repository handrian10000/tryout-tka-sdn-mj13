Koneksi Otomatis ke Google Drive / Google Sheets Pak Handrian

Setiap kali siswa selesai mengerjakan atau kehabisan waktu, nilai akan langsung dikirim ke file Google Sheets di dalam Google Drive Anda secara otomatis.

Status: Belum dikonfigurasi (Nilai tetap tersimpan otomatis di Rekap Dashboard Guru ini).

Panduan Lengkap Menyinkronkan dengan Google Drive (5 Menit):

  1. Buka Google Drive Anda (drive.google.com), klik + Baru (New) → Google Spreadsheet. Beri nama file: Rekap Nilai TKA UPTD SDN Mekarjaya 13.
  2. Pada menu atas Google Spreadsheet, klik Ekstensi (Extensions) → Apps Script.
  3. Hapus semua kode yang ada di editor Apps Script, lalu salin & tempel kode berikut:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Waktu", "Nama Siswa", "Kelas", "No Absen", "Mata Pelajaran", "Paket", "Level", "Skor Benar", "Nilai Akhir", "Durasi", "Status"]);
  }
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.timestamp || new Date().toLocaleString("id-ID"),
    data.nama,
    data.kelas,
    data.absen,
    data.mapel,
    data.paket,
    data.level,
    data.benar + "/30",
    data.nilai,
    data.durasi,
    data.status
  ]);
  return ContentService.createTextOutput(JSON.stringify({result: "success"})).setMimeType(ContentService.MimeType.JSON);
}
  1. Klik tombol Terapkan (Deploy) → Deployment baru (New deployment).
  2. Pilih jenis (ikon gerigi): Aplikasi web (Web app). Pada bagian Yang memiliki akses (Who has access), pilih Siapa saja (Anyone), lalu klik Terapkan (Deploy).
  3. Salin URL Aplikasi Web yang muncul, tempelkan ke kolom URL Web App Google Apps Script di atas, lalu klik Simpan URL. Selesai! Semua hasil siswa otomatis masuk ke Google Drive Anda.

Panduan Meng-online-kan Aplikasi Try Out TKA (Gratis & Permanen)

Karena aplikasi ini dibuat dalam 1 file mandiri (TryOut_TKA_SDN_Mekarjaya_13.html), Pak Handrian dapat meng-online-kannya dalam waktu kurang dari 3 menit secara gratis agar bisa diakses siswa lewat HP/laptop dari rumah!

CARA 1: PALING CEPAT (NETLIFY DROP)

Tanpa Coding — Cukup Drag & Drop

  1. Simpan file aplikasi ini dengan nama index.html di dalam satu folder baru (misal: tka-mekarjaya13).
  2. Buka situs app.netlify.com/drop dan login gratis dengan akun Google/Email Anda.
  3. Tarik (drag & drop) folder tka-mekarjaya13 ke area unggah di browser.
  4. Dalam 10 detik, link website langsung aktif (contoh: tka-sdnmekarjaya13.netlify.app) dan siap dibagikan ke grup WhatsApp kelas!
CARA 2: GITHUB PAGES (GRATIS SELAMANYA)

Cocok untuk Penggunaan Jangka Panjang Sekolah

  1. Buat akun gratis di github.com dan klik New Repository (beri nama: tka-sdn-mekarjaya13, pilih Public).
  2. Klik uploading an existing file, unggah file HTML aplikasi dengan nama index.html, lalu klik Commit changes.
  3. Masuk ke menu Settings → Pages, pada bagian Branch pilih main lalu klik Save.
  4. Tunggu ±1 menit, tautan resmi akan muncul dan dapat dibuka siswa kapan saja dari HP, tablet, maupun laptop.
